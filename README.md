# ASC Portal

This is a [TanStack Start](https://tanstack.com/start) project (TanStack Router + React Query) built with [Vite](https://vite.dev).

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

Routes live in `src/routes/` and are managed by the TanStack Router plugin. The app auto-updates as you edit files.

## Scripts

- `npm run dev` — start the Vite dev server (runs the API contract check first)
- `npm run build` — production build
- `npm run preview` — preview the production build
- `npm run check` / `npm run type-check` — TypeScript type check
- `npm run lint` — run ESLint
- `npm run format` — run Prettier
